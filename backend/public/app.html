Consola de programación

Escribe una sentencia por ejecución para crear rutinas y triggers, consultar datos o recorrer un cursor.

Acceso protegido: configura SQL_CONSOLE_KEY en el archivo .env y recrea el backend con docker compose up -d --force-recreate backend. Esta consola ejecuta cambios reales en la base y solo acepta DDL de funciones, procedimientos y triggers, consultas SELECT, llamadas CALL o una consulta SELECT recorrida con cursor. Un procedimiento invocado con CALL puede modificar datos.

Ejemplo: cursores anidados

Recorre las convocatorias con un cursor externo y, para cada una, abre otro cursor para recorrer sus inscripciones. Carga y ejecuta primero la función; después carga la consulta para ver sus resultados.

El ejemplo solo consulta datos de convocatorias e inscripciones.

DDL permitido: CREATE FUNCTION, CREATE PROCEDURE o CREATE TRIGGER. Envía una sola sentencia; los puntos y coma dentro de bloques $$…$$ son válidos.
